# itself (no --full needed); the report says "config changed".

# ---- CORE / EXTENSION split (LITE CONFIG v1.3, Will, 16 Nov 2026 22:07) --------------------------------------------
# Every gold row goes to exactly one part. CORE = hist\ + current\ (loaded by default). EXTENSION = ext_hist\ +
# ext_current\ (loaded only when the Power Query parameter ALLREPO_SCOPE = "full"; same table, same measures).
# "Window dates" = the last file date of each calendar month (month-ends) + the file dates of the last RECENT_DAYS days.

#       those repo rows are core on window dates only;
#   or SLA_CateCode in WINDOW_SLA and the date is a window date.
# Everything else (07F, 07Y, 07M, 10C, ...; and the thinned rows outside the window) goes to the EXTENSION.
# No measure reads a non-07L row today (16 Nov SX3): the default load changes no page figure.
