# ALLREPO lite gold: every setting of the lite bake in one place
# The lite bake READS the full gold and WRITES a second, separate set of files. The full gold and its job are never
# changed. Re-include a column = remove it from DROP_COLUMNS (or a rounding = remove it from ROUND_COLUMNS), run
# allrepo_lite_run.py, refresh. Any change below changes the config fingerprint, so the next run rebuilds every file by
# itself (no --full needed); the report says "config changed".
